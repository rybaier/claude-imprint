# claude-imprint — Project Rules

These rules govern how Claude works in this repository. They are enforced, not advisory.

<!-- BEGIN claude-imprint rules -->
## Rules

### Process
- Ask before assuming — no silent guesses about intent, architecture, or requirements

### Code Changes
- Simplest solution first — implement the minimum that works, no unrequested abstractions
- Do not touch unrelated code — if a file is not part of the task, leave it untouched

### Communication
- Flag uncertainty explicitly — if not confident, say so before proceeding
<!-- END claude-imprint rules -->
